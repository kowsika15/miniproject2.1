Week 7: Member Management Module — Part 2 (Edit, Delete, Search)

Purpose

Complete full CRUD functionality for members.

Tasks for This Week

  • Implement Edit Member: modify member information and save changes.
  • Implement Delete Member: remove a member after confirmation.
  • Implement Search Member: search by Name, Department, and Member ID.

Concepts Reinforced

  • Consolidating CRUD + search skills
  • Code reuse between Book and Member modules
  • Refactoring repeated logic into shared functions

Week Flow

Process
1. Select Member
2. Edit Member Details
3. Validate Information
4. Save Changes
5. Delete Member After Confirmation
6. Search Member by Name, Department or ID
7. Display Updated Member List
